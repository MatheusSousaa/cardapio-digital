# Cardápio Digital

Aplicação full-stack de um Cardápio Digital, com frontend em React + TypeScript e backend em Java + Spring Boot, com CRUD completo.

## 💻 Requisitos

* Node.js e NPM (para o frontend)
* Java e Maven (para o backend)

## 🚀 Rodando o projeto

Primeiro, clone o repositório:

```bash
git clone https://github.com/MatheusSousaa/cardapio-digital.git
cd cardapio-digital
```

### Backend

```bash
./mvnw spring-boot:run
```

### Frontend

Em outro terminal, na mesma pasta:

```bash
npm install
npm run dev
```

## 🔧 Compilação do Frontend

Para compilar a aplicação para produção:

```bash
npm run build
```

Isso irá gerar uma versão otimizada da aplicação na pasta `dist`.

## 🛠️ Tecnologias

**Frontend:**
* React
* TypeScript
* Vite
* React Query

**Backend:**
* Java
* Spring Boot
* Spring Data JPA
* CRUD completo (Create, Read, Update, Delete)
